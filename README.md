# Depósito Vivo

Prototipo web estático del juego de depósito. No requiere instalar dependencias.

## Jugar localmente

Abrí `index.html` en el navegador.

## Publicar en GitHub Pages

Subí el contenido de esta carpeta a la raíz del repositorio. En Settings → Pages elegí Deploy from a branch, main, / (root).

La partida se reinicia al recargar la página; aún no se guarda el progreso.
